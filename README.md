# ip-02-three-game

《互动编程》作业二 · **互动艺术与电子媒介**（Three.js）

在线游玩：<https://solis887.github.io/ip-02-three-game/>

## 符文小精灵 · 3D 收集小游戏

操控一只头顶符文的小精灵，在夜晚的低多边形草地上收集发光水晶，躲开越来越快的幽灵。

- **开始**：点「开始游戏」进入第一局
- **操作**：WASD / 方向键移动，Shift 冲刺，E 闪避
- **规则**：靠近水晶收集得分并升级，升级后幽灵更多、更快；被幽灵碰到扣一条命，3 条命用完即结束，可一键重开一局

## 技术要点

| 模块 | 实现 |
| --- | --- |
| 场景 | 低多边形草地 + 程序化树木 / 岩石 / 云 / 星星，`SphereGeometry` + `MeshStandardMaterial` |
| 光照 | 半球光 + 平行光（太阳）+ 补光，水晶自发光 |
| 相机 | 第三人称跟随相机，平滑插值，无穿模 |
| 游戏逻辑 | 计分、等级、生命值、无敌帧、胜负判定、重开一局，全部在一个 `index.html` 内，参数集中在顶部 `CONFIG` |

## 运行

纯静态页面，无构建步骤。仓库根目录 `index.html` 即入口，开启 GitHub Pages 后直接打开网址即可玩。
